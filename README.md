# Agentic SDLC: Building a Software Factory

This course builds a set of cooperating agents that automate the software development lifecycle. Each module delivers one agent for a distinct discipline: a Git workflow agent, an arc42 software architecture design agent, a user story requirements agent, a CI/CD deployment pipeline agent, and a TDD/BDD multi-agent test system. The final project combines all of them into an individual kata, producing an end-to-end software factory that turns requirements into tested, deployed software.
